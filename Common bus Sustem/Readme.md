Common Bus System using Registers

Aim

To design a common bus system using registers.

Theory

A bus system transfers data between registers. Multiplexers are used to select which register sends data to the bus.

It reduces wiring complexity and allows efficient data transfer.

Procedure

1. Open Logisim.
2. Place registers.
3. Use multiplexers.
4. Connect outputs to common bus.
5. Use select lines to choose register.

Output

Data from selected register appears on bus.

Result

Bus system transfers data successfully.

Conclusion

Efficient data transfer using common bus is achieved.
