4 Bit Adder

Aim

To design and implement a 4-bit adder circuit using logic gates.

Theory

A 4-bit adder is a digital circuit used to add two 4-bit binary numbers. It is constructed by connecting four full adders in sequence. Each full adder adds corresponding bits along with carry from the previous stage.

The first stage takes no carry input (Cin = 0), and each subsequent stage takes carry from the previous adder. The final stage produces the final carry output.

Procedure

1. Open Logisim software.
2. Place four full adders.
3. Connect inputs A0–A3 and B0–B3.
4. Connect carry output of each adder to next adder.
5. Observe the sum outputs S0–S3.
6. Check final carry output.

Output

Correct binary addition of two 4-bit numbers is obtained.

Result

The 4-bit adder circuit works successfully.

Conclusion

Binary addition using multiple full adders is verified.
