# Experiment 1: Truth Table of Logic Gates

## Aim
To study and verify the truth table of basic logic gates.

## Theory
Logic gates are the fundamental building blocks of digital circuits.

- AND: Output is 1 only when both inputs are 1  
- OR: Output is 1 if any input is 1  
- NOR: Negation of OR  
- XOR: Output is 1 when inputs are different  
- XNOR: Output is 1 when inputs are same
