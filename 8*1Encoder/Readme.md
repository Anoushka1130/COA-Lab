8×1 Encoder

Aim

To design an 8:1 encoder.

Theory

An encoder converts 8 input lines into a 3-bit binary output. Only one input should be active at a time.

Procedure

1. Open Logisim.
2. Use logic gates.
3. Connect 8 inputs.
4. Generate 3-bit output.
5. Test with different inputs.

Output

Binary output corresponding to active input is obtained.

Result

Encoder converts input to binary correctly.

Conclusion

Encoding process is verified.
