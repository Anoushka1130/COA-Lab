Ripple Carry Adder

Aim

To design a ripple carry adder using full adders.

Theory

A ripple carry adder is formed by connecting multiple full adders in series. The carry output of one adder is passed to the next adder. This causes a delay known as ripple delay.

It is simple but slower compared to other adders because each bit must wait for the previous carry.

Procedure

1. Open Logisim.
2. Place multiple full adders.
3. Connect carry-out to carry-in of next stage.
4. Provide binary inputs.
5. Observe output.

Output

Binary sum with carry propagation is observed.

Result

Ripple carry adder performs correct addition.

Conclusion

Carry propagation delay is observed in the circuit.
