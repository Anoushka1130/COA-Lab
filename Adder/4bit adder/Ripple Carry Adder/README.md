## Aim
To implement a Ripple Carry Adder.

## Theory
A Ripple Carry Adder is formed by connecting multiple Full Adders.
The carry output of one stage is given as input to the next stage.
This causes delay known as propagation delay.

## Procedure
1. Connect multiple Full Adders in series.
2. Apply binary inputs.
3. Observe how carry propagates through stages.

## Result
Ripple Carry Adder was successfully implemented and verified.
