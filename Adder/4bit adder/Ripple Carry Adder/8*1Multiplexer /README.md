## Aim
To design and implement an 8×1 Multiplexer.

## Theory
An 8×1 MUX selects one input from 8 inputs using 3 select lines.
Inputs: D0 to D7
Select lines: S2, S1, S0
Output depends on select line combination.

## Procedure
1. Design MUX using logic gates or IC.
2. Provide 8 inputs.
3. Apply select lines.
4. Observe output.

## Result
8×1 Multiplexer was successfully designed and verified.
