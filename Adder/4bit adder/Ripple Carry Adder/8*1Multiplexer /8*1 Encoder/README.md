## Aim
To design and implement an 8×1 Encoder.

## Theory
An Encoder converts multiple inputs into a binary code.
An 8×1 Encoder converts 8 inputs into a 3-bit output.
Only one input should be active at a time.

## Procedure
1. Design encoder circuit.
2. Activate one input at a time.
3. Observe corresponding binary output.

## Result
8×1 Encoder was successfully implemented and verified.
