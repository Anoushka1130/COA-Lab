## Aim
To design a 4-bit binary adder using Full Adders.

## Theory
A 4-bit adder is used to add two 4-bit binary numbers.
It is constructed using four Full Adders connected in series.
Each Full Adder handles one bit and passes carry to the next stage.

## Procedure
1. Connect four Full Adders in sequence.
2. Provide two 4-bit inputs (A and B).
3. Apply input combinations.
4. Observe Sum and Carry output.

## Result
4-bit addition was successfully performed using Full Adders.
