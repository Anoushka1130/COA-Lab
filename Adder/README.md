## Aim
To design and implement Half Adder and Full Adder circuits.

## Theory
An adder is a combinational circuit used for binary addition.
A Half Adder adds two bits (A, B) and produces Sum and Carry.
Sum = A ⊕ B
Carry = A · B

A Full Adder adds three bits (A, B, Cin).
Sum = A ⊕ B ⊕ Cin
Carry = (A·B) + (Cin·(A ⊕ B))

## Procedure
1. Design Half Adder using XOR and AND gates.
2. Design Full Adder using logic gates or two Half Adders.
3. Apply all input combinations.
4. Verify outputs using truth table.

## Result
Half Adder and Full Adder circuits were successfully designed and verified.
