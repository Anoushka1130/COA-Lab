8×1 Multiplexer

Aim

To design an 8:1 multiplexer.

Theory

An 8×1 multiplexer selects one input from 8 inputs using 3 select lines. Based on the select inputs, only one data input is passed to the output.

Procedure

1. Open Logisim.
2. Place multiplexer component.
3. Set inputs = 8.
4. Add 3 select lines.
5. Provide inputs.
6. Observe output.

Output

Selected input appears at output.

Result

Multiplexer works correctly.

Conclusion

Data selection using control signals is verified.
